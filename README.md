# 🎨 SortCraft – Sorting Visualizer (Practice Project)

SortCraft is a simple Sorting Visualizer built to practice and understand the concepts I have learned so far in full-stack development.

This project is **not final** — it will keep improving as I learn new concepts.  
Right now, it helps me understand:

- How frontend and backend communicate using `fetch()`
- How MVC works in a simple Node.js project
- How to structure controllers, routes, and helpers
- How to create animations using JavaScript
- How DSA (Bubble Sort & Selection Sort) works step-by-step
- How to generate visualization frames
- Basic use of `CORS`, `express.json()`, status codes, etc.

---

## 🚀 Features (Current Version)

- Generate random bars (array)
- Visualize:
  - Bubble Sort
  - Selection Sort
- Bar animations with highlights
- Node.js + Express backend for sorting logic
- Frontend in vanilla HTML/CSS/JS
- API returns step-by-step frames for animation
- Beginner-friendly, fully understanding-focused project
